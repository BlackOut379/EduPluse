# EduPluse

An AI-powered academic management and performance analysis platform developed for **Srujan 2026 – Problem Statement AI-03** by **Team THE AIVENGERS**.

EduPluse helps teachers identify where students are struggling through assessment results, learning gap analysis, and individual and class-level performance insights.

## Features
- **Teacher Dashboard:** Manage learning materials, assessments, and student performance.
- **Student Dashboard:** View available assessments, scores, and academic progress.
- **AI-Assisted MCQ Generation:** Generates MCQ drafts from uploaded learning materials using Google Gemini API.
- **Assessment Management:** Create, publish, and manage online assessments.
- **Performance Analysis:** Displays individual and class-level assessment results.
- **Learning Gap Identification:** Highlights subjects and concepts where students need additional support.
- **Authentication:** Separate login access for teachers and students.
- **File Processing:** Supports learning materials in PDF and PowerPoint formats.

## Technologies Used
- **Python:** Backend programming.
- **Flask:** Web application framework.
- **SQLite:** Database management.
- **HTML, CSS & JavaScript:** Frontend development.
- **Google Gemini API:** AI-assisted question generation.
- **PyPDF:** PDF processing.
- **python-pptx:** PowerPoint file processing.
- **PythonAnywhere:** Application deployment.

## How It Works
1. Teachers upload learning materials.
2. AI generates MCQ drafts based on the uploaded content.
3. Teachers review and publish assessments.
4. Students attempt the published assessments.
5. The system records assessment results.
6. Teachers and students can view performance insights and identify learning gaps.
